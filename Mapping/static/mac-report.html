What this experiment establishes

Local image consistency, shared surfaces and camera poses screen map updates. These thresholds are provisional. Initialization may wait for a supported window; after a map loses alignment, further updates stop.

This prototype has no loop closure, global map optimization, calibrated scale or IMU fusion. It is a local DA3 Small experiment, not an installation of the upstream CUDA streaming pipeline.
