How this comparison was made

The baseline uses the original sparse frames. The streak-only control replaces original row 369 with 372, using a previously reviewed exclusion of rows 363–371. This is an explicit annotation, not automatic corruption detection.

The quality selection searches within six frames of each original sampling point. It scores 70% local sharpness rank and 30% spatial feature coverage rank. This preserves the nominal sampling intervals and shared images between windows.

All runs use DA3 Large, the same reviewed undistortion and processing resolution. Neither the alignment algorithm nor its rejection thresholds were tuned after seeing results. The 3% camera discrepancy threshold is relative to estimated scene depth, not measured physical drift.

Selections contain different images, so their pixel-error summaries are not a paired accuracy comparison. No fine-tuning, IMU or ground-truth reference was used.
